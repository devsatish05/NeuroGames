# 🧠 NeuroGames - Brain Teaser Quiz for Kids (7-12 Years)

A fun, interactive brain teaser quiz game for kids! Built with **HTML, CSS, and JavaScript** - No complex frameworks, just pure web magic! ✨

## 🎮 Play Now!

**[👉 CLICK HERE TO PLAY 👈](https://devsatish05.github.io/NeuroGames/)**

Just open the link in your browser and start playing! No installation needed! 🚀

---

## ✨ Features

✅ **10 Fun Brain Teaser Riddles** - Perfect for kids aged 7-12  
✅ **Star Rating System** - Earn ⭐ for each correct answer  
✅ **Achievement Badges** - 👑 (Genius) 🥇 (Excellent) 🥈 (Great) 🥉 (Good) 🎯 (Keep trying)  
✅ **Progress Tracking** - Visual progress bar shows how far you are  
✅ **Sound Effects** - Beep sounds for correct/incorrect answers  
✅ **Confetti Celebration** - Animated confetti on correct answers! 🎉  
✅ **Review Answers** - Learn why you got it wrong  
✅ **Fully Responsive** - Works perfectly on phones, tablets & computers  
✅ **Kid-Friendly Design** - Colorful, fun, and easy to understand

## 🚀 How to Play

1. **Click "Start Quiz"** button
2. **Read the brain teaser** carefully
3. **Select one option** (A, B, C, or D)
4. **Get instant feedback** - ✓ Correct or ✗ Incorrect
5. **Click "Next"** to go to the next question
6. **See your final score** with a badge
7. **Click "Review Answers"** to learn from mistakes
8. **Play again** to beat your high score! 🏆

---

## 📊 How Scoring Works

- Each correct answer = **1 Star ⭐**
- 0-39% = 🎯 Badge (Keep trying!)
- 40-59% = 🥉 Badge (Good effort!)
- 60-79% = 🥈 Badge (Great job!)
- 80-99% = 🥇 Badge (Excellent!)
- 100% = 👑 Badge (Brain Genius!)

## 🎨 Customization Guide

### Add Your Own Brain Teasers

1. Open `script.js`
2. Find the `quizQuestions` array
3. Add a new riddle:

```javascript
{
    question: "Your riddle here?",
    options: ["Wrong", "Wrong", "Correct", "Wrong"],
    correct: 2,  // Index of correct answer (0-3)
    emoji: "🧠"
}
```

### Change Colors

Open `style.css` and find the gradients. Change colors like:
- `#667eea` → any color code
- Use [this tool](https://www.color-hex.com/) to pick colors
